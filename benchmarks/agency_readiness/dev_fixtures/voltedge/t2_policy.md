## Current policy

Must never use the word "curated" in public copy.

Instagram is the primary channel for launches.

Each configuration is tested against the same quality standard before
release. Pricing varies by region and volume, with discounts for
educational and nonprofit customers. Can I return an opened item? Yes,
within thirty days with the original receipt. Compatibility charts show
which accessories work with which model variant. The specifications
table lists dimensions, weight, power draw, and operating temperature.
The mobile application syncs across devices using end-to-end encryption.
