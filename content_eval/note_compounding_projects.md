# Side Projects That Compound

Not all projects are equal — some form a portfolio of isolated demos, others build on each other.

## The Compounding Test

Before starting: does this project reuse, extend, or get reused by prior work? The parser fed the PDF extractor; the CLI tools shaped Mind Palace's interface; the retrieval projects ladder directly into each other. Isolated projects teach isolated lessons.

## Portfolio vs Ladder

A portfolio of unrelated demos shows breadth. A ladder shows judgment — each project's existence is justified by what the previous one revealed. For learning purposes, ladders win because problems inherit context.

## Kill Criteria

Compounding cuts both ways: a project that stops teaching anything should end even if unfinished. The habit of finishing everything is how compounding stalls.
