# Effort Estimation That Works

Personal projects have the worst estimation bias: no external deadline forces honesty.

## Reference-Class Forecasting

Instead of reasoning about the task ("should take a weekend"), find comparable finished work ("the last three retrieval features each took two weeks"). Historical base rates beat intuitive decomposition every time.

## The Planning Fallacy in ML

ML projects add a unique failure mode: the evaluation reveals the approach doesn't work. Budget for the *investigation*, not just the implementation — a feature whose viability is unknown is a research question wearing an engineering costume.

## Scope Anchors

Write down what "done" means before starting. The context-budget milestone was scoped as "explicit, tested budget" — which is why it ended when the tests passed rather than expanding into a tuning exercise.
