# Chord Progression Assistant

Music-theory tooling — a non-ML project exercising data modeling of a domain with strict rules.

## Features

- Chord construction from intervals; enharmonic-aware spelling
- Diatonic progression suggestions by key with common-function transitions
- Practice randomizer: key-constrained progressions at configurable difficulty
- Roman-numeral analysis input mode

## Note

A rules-first project where the domain's determinism makes exhaustive correctness achievable — a useful contrast to the probabilistic ML systems, and a reminder that not every problem needs a model.
